- **곡명·아티스트·순위만 차트에서 확인했습니다.** BPM·RMS 값은 앱 사용 흐름을 보여주려고 임의로 정한 **가상값**이며 실제 곡을 측정한 값이 아닙니다.

- Melon 장르별(랩/힙합) 차트는 이번 검색으로 최신 자료를 확인하지 못해, 종합 TOP100 안에서 힙합·R&B 성향 곡을 골랐습니다.
